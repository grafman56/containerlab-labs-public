# The spreadsheet you used to keep in your head.
#
# In a hierarchical design the PREFIX was the location. 10.20.30.0/24 meant
# the nursing building, third floor, because you decided that at design time
# and then cabled it that way. You could read a place off an address with no
# tool at all.
#
# EVPN takes that away on purpose: the same VNI is live on every leaf and the
# anycast gateway is the same address everywhere. Location did not disappear
# though -- it MOVED, out of the prefix and into the next-hop. A type-2 route
# says "this MAC is behind VTEP 10.255.0.1 in VNI 1010", and that VTEP is a
# leaf, and a leaf is in a closet, in a building.
#
# So: the VTEP loopback plan is the new subnet plan, and it deserves the same
# care you used to give the subnet plan. Number it with geography in it, e.g.
#
#     10.255.<site>.<building><closet>
#
# and every type-2 route in the fabric carries a readable location for free.
# This lab deliberately does NOT do that -- leaves are 10.255.0.1 to .4, flat
# and geography-free, which is the common mistake. This file is the patch over
# it, and the reason you want the numbering instead of the file.
#
# A real one is NetBox or Catalyst Center or BlueCat's IPAM tree, and the
# lookup is an API call. The format matters less than the fact that something
# must answer "which closet is 10.255.0.1".
#
# Format:  key = place
# Keys:    a leaf name, a VTEP loopback, or leaf/interface for a patch panel
#          port.
